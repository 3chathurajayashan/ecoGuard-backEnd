# Use-case traceability: Manage Ranger Patrols

| Flow                                                | Endpoint / class                                                                                         | Test                                                                                                                              |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Main: ranger views assigned patrol route            | `GET /api/rangers/:rangerId/assignment`; `AssignmentService.getAssignmentForRanger()`                    | `HTTP contract › ranger retrieves their assignment`; `AssignmentService › assigns a route and loads the latest ranger assignment` |
| Main: park manager assigns ranger a route           | `POST /api/assignments`; `AssignmentService.assignPatrol()`                                              | `HTTP contract › park manager assigns a route`; `AssignmentService › assigns a route and loads the latest ranger assignment`      |
| Main: ranger syncs a completed patrol               | `POST /api/patrols/sync`; `PatrolSyncService.receivePatrol()`                                            | `PatrolSyncService › stores a completed patrol as synced`; HTTP sync integration                                                  |
| Main: manager lists synced patrols                  | `GET /api/patrols`; `PatrolController.listPatrols()`                                                     | HTTP sync/list integration                                                                                                        |
| Main: manager reviews patrol coverage               | `GET /api/patrols/:patrolId/coverage`; `CoverageService.reviewPatrolCoverage()` and `CoverageCalculator` | `CoverageService › returns the coverage report`; HTTP coverage integration                                                        |
| A1: retry sync safely after connectivity returns    | Atomic unique `patrolId` upsert in `MongoosePatrolRepository.upsertByPatrolId()`                         | `PatrolSyncService › same patrol id is stored once`; Mongoose upsert integration                                                  |
| A2: ranger has no assigned route                    | `GET /api/rangers/:rangerId/assignment` returns `NO_ASSIGNED_ROUTE`                                      | HTTP E1 response assertion; `AssignmentService › reports ranger with no assignment`                                               |
| A3: manually record a field waypoint                | `Waypoint.createManualPoint()` Factory Method; waypoint validation in sync validator                     | Domain manual-point tests; HTTP invalid waypoint aggregation test                                                                 |
| A4: complete patrol before synchronization          | Sync validator requires `PatrolStatus.COMPLETED`; `Patrol.complete()` guards end time                    | `PatrolSyncService › rejects incomplete patrols and end time before start time`; domain lifecycle tests                           |
| A5: manager sees covered and neglected route points | `CoverageService` applies the swappable 50 m haversine strategy                                          | Domain full/partial/none/empty/threshold tests; coverage service and HTTP tests                                                   |
| E1: ranger has no assignment                        | `AssignmentService.getAssignmentForRanger()` throws `NotFoundError` code `NO_ASSIGNED_ROUTE`             | HTTP assignment E1 test                                                                                                           |
| E2: sync body is invalid                            | `validateSyncPatrol()` aggregates Zod failures into `ValidationError.errors`                             | Domain/service invalid waypoint test; HTTP 400 `errors[]` test                                                                    |
| E3: patrol end precedes start                       | `validateSyncPatrol()` rejects end time before start time                                                | `PatrolSyncService › rejects incomplete patrols and end time before start time`                                                   |
| E4: referenced patrol does not exist for review     | `CoverageService.reviewPatrolCoverage()` throws `NotFoundError`                                          | HTTP unknown patrol coverage test                                                                                                 |
